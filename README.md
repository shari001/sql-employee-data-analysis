# SQL Employee Data Analysis

This project demonstrates SQL queries written to analyze employee data.

## Tools Used
- MySQL
- SQL

## File Included
- employee_analysis.sql – contains table creation, data insertion, and analysis queries

## Concepts Used
- CREATE, INSERT, SELECT
- WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate functions (COUNT, SUM, AVG)

## Sample Insights
- Department-wise salary comparison
- Highest and lowest paid employees
